# gidi-en student v2 (seed 1)

**Verdict: PASS the pre-declared protocol** (`protocol.json`, written before any v2 training or
scoring, thresholds unchanged). Scored with word snapping on, as declared. One seed, one run,
last epoch, no selection. Labels are **silver** (Gemini + Clef + Claude adjudication; training
labels from the Clef kNN teacher): every number is agreement with those labels, not human truth.

## What changed vs v1

1. **Data**: `silver-slang-train.jsonl` adds slang / abbreviation / Gen Z notes, labelled by the
   same few-shot kNN Clef teacher as `silver-train` (pool = seed only, 16-shot pass A + 12-shot
   reversed pass B). Training set = silver-train 1,462 + labels-seed 280 + **613 consistent
   slang notes = 2,355** (v1: 1,742).
2. **Decode**: whole-word snapping of the predicted span (`snap_words`).
3. Recipe unchanged: v1 init (`models/gidi-en-v1-init`, vocab pruned from the v1 train split; the
   byte-level BPE has no UNK, so new slang tokens fall back to pieces), 40 epochs, batch 8,
   lr 5e-5 / head 1e-3, warmup 0.1, MPS. `run.sh` is the exact command sequence.

## Snapping (item 3)

`evaluate_onnx.decode(..., snap_words=True)` applies `gidi.inference.decode.snap_to_words` (the
Vietnamese v3 rule, ported in the playground). Documented in `docs/annotation-en-v1.md`
("Inference: word-boundary snapping"): it is **not** in the ONNX graph; a runtime must apply it
after BIO decoding. Free ablation on v1 (int8, snap on vs off):

| v1 | raw | snapped |
|---|---|---|
| slang probe target / joint | 0.754 / 0.664 | 0.756 / 0.667 |
| test primary type F1 / target | 0.934 / 0.869 | 0.934 / 0.879 |
| test secondary type F1 / target | 0.883 / 0.834 | 0.883 / 0.838 |
| dev target | 0.788 | 0.799 |

Snapping alone is small: it fixes the `pap`/`ist`/`um` fragments but not wrong-span errors.

## Extra: Gen Z probe (not gating)

`datasets/probe-en-genz`: 100 held-out Gen Z notes, never trained on. Labels: Gemini and Clef
zero-shot agreed on 71 (consensus), Claude adjudicated 29 (23 complete, 5 uncertain, 1 skipped).
94 complete notes are scored. Notes were chosen by id-hash order before labelling, so the type
mix is whatever Gemini wrote (borrow 19, repayment_out 20, expense 25, lend 9, repayment_in 10,
income 8, transfer 6, refund 2). Small n: one note is 1.1 points.

## Artifacts and caveats

- **int8: `models/gidi-en-v2-onnx/seed1/model.int8.onnx` = 29,166,949 bytes (29.17 MB)**;
  fp32 `model.onnx` 116,057,730 bytes. Checkpoint `models/gidi-en-v2/seed1` (gitignored).
- Results: `results.json` (raw + snapped, protocol checks), `slang-probe.json`,
  `slang-probe-snap.json`, `genz-probe-snap.json`, `genz-probe-v1-snap.json`; v1 ablations in
  `experiments/gidi-en-student-v1/results-snap-ablation.json` and `slang-probe-snap.json`.
- The slang probe and the Gen Z probe share the same generator family (Gemini) as the new
  training notes, so part of the gain may be style familiarity, not general slang robustness.
  Silver labels of both sides come from the same Clef family (the slang probe via zero-shot
  Clef + Gemini + Claude, training via the kNN teacher). Treat the margin over the thresholds
  (+0.034 joint, +0.035 target, +0.020 type) as modest; one seed gives no variance estimate.
- Gen Z notes were written by an LLM, not collected from real users.
- A first v2 training launch was killed ~1 minute in and restarted after
  `check_note_similarity.py` flagged 2 training notes; no result from the first launch was read.
