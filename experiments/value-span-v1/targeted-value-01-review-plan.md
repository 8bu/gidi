## Escalation rule (predeclared)

- Error: a human label differs from the proposal on type, target span or value span, or the human annotation_status is not 'complete' (either pass).
- (a) any error in a hard-pattern stratum -> review that entire stratum.
- (b) Clean audit: 0-1 errors -> accept the auto-accepted remainder; >=2 errors -> stop and expand review to all auto-accepted records.
- (c) Must-review: errors do not trigger escalation (expected); they are reported.

Apply it with `uv run python scripts/score_value_review.py --dataset targeted-value-01`
once both Quet passes exist; it writes the verdicts into
`experiments/value-span-v1/review-score.json`.

## Quet commands

Two passes over the same small queue (type/target, then value):

```sh
quet annotate datasets/annotation-v2/targeted-value-01/review-queue.jsonl \
  --schema configs/annotation-v1.yaml \
  --out datasets/annotation-v2/targeted-value-01/labels.jsonl \
  --proposals datasets/annotation-v2/targeted-value-01/review-type-proposals.jsonl

quet annotate datasets/annotation-v2/targeted-value-01/review-queue.jsonl \
  --schema configs/annotation-v2-value.quet.yaml \
  --out datasets/annotation-v2/targeted-value-01/value-labels.jsonl \
  --proposals datasets/annotation-v2/targeted-value-01/review-value-proposals.jsonl
```

`--out` is strict: labels must be ids of the queue. Proposals are advisory; only the
reviewer's confirmed decision is saved. Afterwards:

```sh
uv run python scripts/validate_annotations.py datasets/annotation-v2/targeted-value-01/labels.jsonl \
  --queue datasets/annotation-v2/targeted-value-01/review-queue.jsonl
uv run python scripts/score_value_review.py --dataset targeted-value-01
```
